# Код-ревью в команде «Поиск»

- Каждый merge request требует двух одобрений: одного от ML-инженера и одного от backend-разработчика.
- Изменения моделей сопровождаются отчётом офлайн-метрик в описании MR.
- Ноутбуки в репозиторий не коммитим — только код пайплайнов.
- Срок ревью — два рабочих дня.
