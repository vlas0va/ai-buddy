# Где хранятся ключи и секреты

- Секреты сервисов (пароли БД, токены, ключи API) хранятся в хранилище секретов (Vault). Сервисы получают их при запуске.
- В git секреты не попадают никогда: ни в код, ни в конфиги, ни в историю коммитов. В CI стоит проверка на утечки.
- Для локальной разработки используй файл `.env` по шаблону `.env.example` с тестовыми значениями; `.env` в git не добавляй.
- Доступ к секретам стенда выдаёт наставник через заявку с согласованием руководителя.
- Если случайно закоммитил секрет — сразу скажи наставнику: ключ нужно отозвать и выпустить новый, удаления коммита недостаточно.
- Не вставляй секреты, логи с токенами и внутренний код в публичные нейросети и чаты.
