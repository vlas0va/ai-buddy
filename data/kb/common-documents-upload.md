# Куда отправлять документы

| Документ | Куда |
|---|---|
| Кадровые документы (договор, заявления, справки с прошлых мест) | кадровый портал, раздел «Мои документы»; вопросы — HR admin |
| Больничный лист | HR BP по его инструкции, без диагноза |
| Документы для вуза (договор о практике, характеристика) | куратору стажировки, заранее — минимум за 3 недели |
| Чеки для компенсаций | раздел «Компенсации» кадрового портала |
| Рабочие документы по задачам | пространство команды в Confluence |

Не отправляй сканы паспорта и другие персональные документы в рабочие чаты и в AI-buddy.
