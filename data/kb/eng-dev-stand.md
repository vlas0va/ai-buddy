# Dev-стенд и локальное окружение

## Локально
- Сервис поднимается одной командой `docker compose up` по README репозитория; зависимости (PostgreSQL, Redis, Kafka) запускаются в контейнерах.
- Поддерживаемые ОС: macOS и Linux; на Windows — через WSL2.
- Если сервис не стартует — проверь, что запущен Docker и свободны порты из README.

## Dev-стенд
- У каждой команды есть общий dev-стенд и личные окружения по запросу на время задачи.
- Ветка раскатывается в личное окружение командой из pull request (кнопка «Deploy to dev»).
- Тестовые данные на стенде синтетические; реальные данные пользователей на dev недоступны.

## Куда смотреть
- Логи и метрики сервиса — Grafana команды. Ошибки — в логах контейнера (`docker compose logs <сервис>`).
