# Основы защиты персональных данных — тестовая версия

Это синтетическая учебная выжимка для прототипа. Официальный источник — лендинг «Защита данных» во внутренней базе знаний компании; проходить нужно именно его.

Главное:
- Персональные данные — любая информация, по которой можно определить человека: ФИО, телефон, адрес, идентификаторы.
- Не выгружай данные пользователей на личные устройства и во внешние сервисы, включая публичные нейросети.
- Для отладки используй обезличенные или синтетические данные.
- Доступ к данным запрашивается по принципу минимально необходимого.
- Если заметил утечку — сразу сообщи в службу информационной безопасности.
