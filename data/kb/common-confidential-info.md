# Работа с конфиденциальной информацией — тестовая версия

Синтетическая выжимка для прототипа. Официальный документ — политика по работе с КИ и её защите.

- Конфиденциальная информация — всё, что не опубликовано компанией официально: код, документы, метрики, переписка.
- Храни её только в корпоративных системах, не пересылай в личные мессенджеры.
- Делись ею только с теми, кому она нужна для работы.
