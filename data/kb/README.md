# Синтетическая база знаний AI-buddy

Все документы — **тестовые инструкции прототипа** (`source_type: test`), написаны командой для хакатона по мотивам
чек-листа стажёра и открытых материалов Авито. Это не регламенты Авито (R69). Имена людей и команды вымышлены (R68).

Формат: Markdown + frontmatter.
```yaml
doc_id: delivery-code-review          # уникальный id, совпадает с именем файла
title: "Как у нас проходит код-ревью"
source_type: test                     # всегда test
acl: {roles: [intern, mentor, lead], teams: [delivery]}   # "*" — все команды
checklist: [CL-07]                    # пункты чек-листа Авито, которые покрывает документ
tags: [код-ревью]
updated: 2026-11-01
```
Правило прав: документ попадает в LLM, только если роль **и** команда пользователя входят в `acl` (фильтр до ранжирования, ADR-003).

| Группа | Документы | Чек-лист |
|---|---|---|
| Общие (все команды) | 19: отгул, отпуск, больничный, куратор, защита данных, раскрытие информации, КИ, практика, экватор, выпускной, первый день, доступы, бенефиты, командировки, наставник, к кому идти, кадровые вопросы, выпускники | CL-02…CL-16 |
| Команда «Доставка» | 8: кто есть кто, каналы, пространство, код-ревью, ритуалы, инструменты, первая задача, дежурства | CL-03…CL-07 |
| Команда «Поиск» | 7: кто есть кто, каналы, пространство, код-ревью, ритуалы, инструменты, первая задача | CL-03…CL-07 |
| Только наставник / руководитель | 3: методичка наставника, обратная связь, согласование заявок | CL-02, CL-06, CL-12 |

Ответ наставника на эскалацию можно превратить в новый документ (`POST /v1/kb/faq-draft`, `origin: escalation`) — так FAQ команды растёт (R10).
