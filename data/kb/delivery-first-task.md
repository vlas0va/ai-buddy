# Первая задача стажёра в «Доставке»

Первая задача — небольшая доработка с тестами, которую наставник выбирает в первую неделю. Цель — пройти весь путь: задача в Jira → ветка → MR → ревью → деплой на стейджинг.
Самостоятельной задачей считается задача, которую ты довёл до релиза без парного программирования с наставником.
