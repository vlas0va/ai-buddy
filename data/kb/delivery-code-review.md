# Код-ревью в команде «Доставка»

- Каждый merge request ревьюит минимум один разработчик команды; для стажёра первым ревьюером всегда выступает наставник.
- MR до 400 строк; большие изменения разбивай на части.
- В описании — ссылка на задачу в Jira и как проверить изменения.
- Ревью делаем в течение одного рабочего дня. Если MR висит дольше — напиши в #delivery-team.
- Перед мержем обязательно зелёный CI и покрытие тестами не ниже 80% для нового кода.
