# К кому с чем идти

| Вопрос | К кому |

| Задачи, код, процессы команды | наставник |
| Цели стажировки, отгулы и отпуск, повышенные доступы | руководитель команды |
| Методичка, экватор, выпускной, документы для вуза | куратор стажировки |
| Кадровые вопросы, больничный, оплата | HR BP |
| Ноутбук, учётка, пропуск | служба поддержки |
