# Тексты слайдов зоны A (для презентации C)

## Слайд «Как устроен AI-buddy внутри»
- **Гибридный агент.** Пишущие сценарии (отгул, доступы, согласования) — детерминированные автоматы: черновик → «Отправить» →
  MCP-сервис → карточка с номером → запись в журнале. LLM — там, где важен язык: ответы по базе знаний со ссылками.
- **Один конфиг `agent.yaml`**: промпт, модель, MCP-серверы, инструменты по ролям — как внутренний инструмент Авито
  «промпт + MCP». Новый сервис = новый MCP-инструмент + строка в конфиге.
- **Работает без ключа**: stub по умолчанию, любой OpenAI-совместимый API или локальная модель одной переменной.
- **Обученный роутер намерений**: логистическая регрессия на 286 фразах, 94% на отложенном наборе; обучается за секунды.

## Слайд «AI и права»
Пять рубежей — ошибка модели не превращается в утечку:
1. **Guardrails до LLM**: чужие данные, зарплата и медицина, найм и увольнения, «игнорируй инструкции» — отказ правилами.
2. **Фильтр документов до LLM**: модель видит только документы своей роли и команды; агент перепроверяет ACL сам.
3. **Инструменты по ролям**: стажёру не предлагается `approvals.decide`; пишущих инструментов LLM не видит вообще.
4. **Проверка в MCP-сервере**: каждый вызов — с токеном пользователя; только свои записи, руководитель — только своя команда.
5. **Подтверждённая запись**: HMAC-токен связывает пользователя, черновик и хеш аргументов; повтор не создаёт дубль.
Доказательства: 92 eval-кейса (guard-метрики 100%), 170 тестов, покрытие 97%, 137 сценариев спек → тесты.

## Слайд «Метрики и пилот»
- **North Star**: время до первой самостоятельной задачи (−20% к контролю).
- **Наставнику**: −30% рутинных обращений; ≥ 8 из 40–48 часов за программу возвращаются на содержательную работу.
- **Качество**: ≥ 70% вопросов без эскалации, ≥ 80% «полезно», ≥ 95% действий с первой попытки.
- **Защитные**: 100% корректных отказов, p95 локальных действий < 1 с.
- **Пилот**: feature flag по командам → difference-in-differences к контролю и прошлой когорте → опросы на 2-й неделе и
  экваторе → раскатка после экватора; стоп-кран — флаг выключается за минуту.
