# ADR-003. Трёхрубежная модель прав + подтверждение записи

Статус: принято · Владельцы: A (рубежи 1–2), B (рубеж 3, токены) · Требования: R22, R71, R72, R66

## Контекст
AI-buddy видит запросы стажёра на естественном языке, в том числе попытки получить чужие данные или выполнить операцию
от чужого имени, включая prompt-injection. Права пользователя уже есть в Авито (авторизация, роли) — их надо соблюдать, а не дублировать.

## Решение
| Рубеж | Где | Что гарантирует |
|---|---|---|
| 0. Детерминированные guardrails | агент, до LLM | Запросы про зарплату, компенсации, медицину, найм/увольнение, чужие данные, «игнорируй инструкции» отклоняются правилами, LLM их не видит |
| 1. Фильтр документов до LLM | mcp-kb (B) + повторная проверка ACL в агенте (A) | LLM никогда не получает документ, который роль/команда пользователя не может читать |
| 2. Инструменты по ролям | `agent.yaml` | LLM предлагаются только читающие инструменты роли; пишущих инструментов LLM не видит вообще |
| 3. Проверка в MCP-сервере | каждый MCP-сервер (B) | Токен пользователя проверяется на каждом вызове: только свои записи, руководитель — только своя команда |
| 4. Подтверждение записи | core + агент + MCP | Запись — только в confirm-ходе по подтверждённому proposal: HMAC-токен (формат `contracts/mcp-tools.md`) связывает пользователя, proposal и `sha256(canonical_json(args))`; агент дополнительно сверяет proposal со своим реестром; `idempotency_key = proposal_id` |

Агент дополнительно сверяет `user_context` с claims JWT: подменить роль или команду в теле запроса нельзя.

## Почему так
- Ошибка LLM не превращается в утечку: модель физически не получает чужих данных и не имеет пишущих инструментов.
- Повтор запроса после сбоя не создаёт дубль (идемпотентность).
- Замена имитации на реальный сервис не ослабляет защиту: рубеж 3 остаётся в адаптере MCP.

## Проверка
Матрица «роль × инструмент × ресурс» (тесты MCP у B), тесты агента `test_RG_*`, eval-кейсы `refusal`, `injection`, `rights`
(цель — 100% корректных отказов, отчёт `eval/reports/latest.md`).
