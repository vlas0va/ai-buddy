# ADR-001. Язык сервиса агента: Python 3.12 + Flask

Статус: принято · Владелец: A · Требования: R59, R53, R60, R77

## Контекст
Стек Авито — Go на бэкенде, Python + Flask «в отдельных случаях». Сервис агента — особый случай: оркестрация LLM, RAG,
eval-набор, обучение и оценка классификатора намерений, работа с MCP. Ядро и имитации корпоративных сервисов остаются на Go (B).

## Решение
Сервис агента пишем на Python 3.12 + Flask, отдаём ответ потоком SSE. Gunicorn с потоковыми воркерами (`gthread`),
pydantic для схем, httpx для LLM и MCP (streamable HTTP), pytest + pytest-cov, ruff.

## Почему не Go
| Критерий | Python + Flask | Go |
|---|---|---|
| Зрелость LLM/MCP SDK, RAG, eval, обучение моделей | высокая | средняя |
| Совместимость со стеком Авито | допускается ТЗ («Flask в отдельных случаях») | полная |
| Скорость итераций по промптам и eval | высокая | ниже |
| Производительность | достаточно: узкое место — LLM, а не сервис | выше |

## Последствия
- Контракт (`contracts/agent-stream.md`) не зависит от языка: агент можно переписать на Go без правок core и web.
- Агент stateless по запросу, состояние диалога — в Redis (`REDIS_URL`), поэтому горизонтально масштабируется.
- Одна точка конфигурации — `agent.yaml` (промпт, модель, MCP-серверы, инструменты по ролям) — повторяет внутренний
  инструмент Авито «промпт + MCP» (R53).
