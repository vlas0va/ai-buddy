## README — обязательные разделы (R32–R36, R41, R44)
1. Ссылка на видео и презентацию (первым экраном).
2. Быстрый старт: требования (Docker, RAM), одна команда запуска, адреса.
3. Тестовые учётные данные (таблица из product.md).
4. Порядок проверки: пошагово по каждому заявленному сценарию.
5. Тесты: `make test`, `make e2e`, `make coverage`, где лежит отчёт.
6. LLM и ключи: сервис, модель, переменные, как подключить свой ключ, stub по умолчанию.
7. Версии зависимостей.
8. Архитектура и ADR — ссылки; SDD — где лежат спеки.
9. Ограничения прототипа: синтетические данные, тестовые инструкции не являются регламентами Авито.
